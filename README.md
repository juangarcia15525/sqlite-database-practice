# SQLite Database Practice

## Descripción

Este proyecto es una práctica básica de bases de datos usando SQLite desde IntelliJ IDEA.

El objetivo principal es aprender a crear una base de datos, crear tablas, insertar datos y consultar la información usando SQL.

---

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- SQLite
- SQL
- Git
- GitHub

---
